# cavaldos Homebrew Tap

Install packages with:

```bash
brew tap cavaldos/tap
brew install <package>
```

## Packages

| Package | Description |
| ------- | ----------- |
| `ice` | Free and open-source menu bar manager for macOS ([cavaldos/Ice](https://github.com/cavaldos/Ice)) |
| `thorion` | Menu bar battery monitor and charge limiter for Apple Silicon MacBooks ([cavaldos/Thorion](https://github.com/cavaldos/Thorion)) |

```bash
brew tap cavaldos/tap
brew install cavaldos/tap/ice
```

```bash
brew install --cask cavaldos/tap/thorion
```
